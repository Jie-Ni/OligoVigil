# OligoVigil versioned access

The manuscript-cited v1.0.1 data snapshot is archived at [Zenodo](https://doi.org/10.5281/zenodo.20633779).

The current v1.0.2 web release is available at [oligovigil.pages.dev](https://oligovigil.pages.dev/). It provides the same reported release totals—737 observations, 626 toxicity records, 111 off-target records, 660 primary studies, and 344 benchmark split rows—with release-scoped CSV, JSON, audit, provenance, and checksum resources.
