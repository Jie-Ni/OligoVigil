# Changelog: v1.0.2

## Release

- Published the v1.0.2 web release at <https://oligovigil.pages.dev/>.
- Retained the manuscript-cited v1.0.1 data snapshot at <https://doi.org/10.5281/zenodo.20633779>.
- Exposed 737 evidence records, 626 toxicity records, 111 off-target records, 660 release-linked primary studies, 737 release audit rows, and 344 benchmark split rows.
- Added release-scoped CSV, JSON, source provenance, data dictionary, and checksum resources.
- Normalized PMCID values to canonical `PMC` identifiers across the database and generated release tables.
- Rebuilt `all_tables.zip` as a deterministic release-only bundle.
- Updated the portal around evidence browsing, source lookup, downloads, curation methods, and citation.
