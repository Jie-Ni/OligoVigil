Current release: 737 human curator-verified evidence records. The public release contains 626 toxicity records and 111 off-target records. Candidate rows are kept separate from citable release evidence; unsupported candidates are not shown as verified records. Every release row links to source metadata, an exact source location, evidence grade, and audit status.
